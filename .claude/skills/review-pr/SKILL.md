# Перевірка гілки перед pull request

Мета — щоб автор побачила незалежний висновок **до** того, як зміни підуть
у pull request, і могла зупинити те, що їй не подобається.

## Кроки

1. Переконайся, що є що перевіряти: `git diff main...HEAD --stat`. Якщо diff
   порожній — скажи про це й зупинись.
2. Запусти агента `code-reviewer` (через Agent tool, subagent_type
   `code-reviewer`) із завданням: «Перевір зміни поточної гілки відносно
   `main` за своїм чеклістом і дай висновок у своєму форматі.»

   Агент не пам'ятає попередніх запусків; без історії він починає з нуля,
   піднімає закрите й міняє рівні знахідок. Історія кіл гілки живе у файлі
   `.review-rounds/<гілка>.md` (у назві гілки `/` замінити на `-`; тека в
   `.gitignore`, тож файл переживає перезапуск сесії й не потрапляє в git).
   Якщо файл є:
   - у розділі `### Рішення авторки` останнього кола, якщо там «ще не
     записані», заміни цей рядок на рішення
     авторки по кожній знахідці: «виправлено комітом `<хеш>`», «відхилено
     авторкою — <чому>» або «перевірено зовні — <як і що показало>». Бери їх
     із цієї сесії; чого не знаєш — спитай авторку, не вгадуй. Знахідка без
     рішення — «відкрита»;
   - додай до завдання агента блок **«Попередні кола»** — лише шлях і
     вимогу, дослівно: «Попередні кола: `.review-rounds/<гілка>.md`.
     Прочитай цей файл повністю, перш ніж починати перевірку.» Вміст файлу
     в завдання не копіюй: переказ губить або скорочує висновки.
3. Покажи висновок автору **дослівно**, без скорочень і без власних
   виправлень до нього — це незалежна думка, і її цінність саме в цьому.
4. Після висновку додай один рядок від себе: чи згоден ти з ним, і якщо
   ні — з чим саме й чому. Не переписуй знахідки, не пом'якшуй їх.
5. Допиши в `.review-rounds/<гілка>.md` розділ `## Коло N — <дата>, HEAD
   <короткий хеш>` з висновком дослівно, а під ним — підрозділ
   `### Рішення авторки` з рядком «ще не записані». Якщо файлу немає (перше
   коло гілки), спершу створи теку `.review-rounds/` і файл із заголовком
   `# /review-pr — <гілка>`: без нього друге коло почнеться без історії.
6. Більше нічого не виправляй і не пушай. Рішення, що робити зі знахідками,
   — за автором.
